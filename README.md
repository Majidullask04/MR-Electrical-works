# ⚡ MR. ELECTRICAL WORKS — Official Web Application

A modern, high-converting, enterprise-grade web application built for **MR. ELECTRICAL WORKS**, a local electrical engineering and contracting business based in Patancheru & Hyderabad, Telangana. 

Designed to establish high client trust, showcase technical electrical expertise across residential, commercial, and industrial sectors, and drive direct lead conversions via Phone and WhatsApp integrations.

---

## 🌍 Real-World Application & Business Impact

This application is designed specifically as a **digital front-door & local lead-generation machine** for an electrical contracting business operating in competitive regional markets.

### Key Business Goals & Real-World Use Cases:
1. **Local Lead Generation**: Instant contact capabilities through sticky, floating quick-action buttons (Direct Phone Calling & 1-Click pre-filled WhatsApp inquiry messages).
2. **Establishing Technical Credibility**: Highlights credentials such as lead engineer **Nekbor Seikh (M.Tech - EEE)**, M.Tech EEE qualification, 5+ years of operational experience, and safety compliance certifications.
3. **Multi-Sector Service Showcase**:
   - **Residential**: Full house wiring, DB box setup, safety EARTHING, lighting.
   - **Commercial**: Offices, retail stores, hospitals, schools, and hotel electrical setups.
   - **Industrial**: Heavy factory wiring, machine connections, cable tray installations, and high-voltage power distribution systems.
4. **Interactive Portfolio**: Showcases real-world completed projects across Patancheru, Bolarum Industrial Area, and Hyderabad with categorization, duration, and client types.
5. **High Conversion & Mobile First**: Optimized for local users browsing on smartphones looking for emergency electrical repair or planned project quotations.

## 🚀 Getting Started & Local Development

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) (v18+ recommended) and `npm` installed.

### Installation

1. **Clone or Navigate to Project Directory**:
   ```bash
   cd "mr electrical"
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Start Development Server**:
   ```bash
   npm run dev
   ```
   The app will run locally at `http://localhost:5173`.

4. **Build for Production**:
   ```bash
   npm run build
   ```
   The production-ready assets will be compiled into the `dist/` directory.

5. **Preview Production Build**:
   ```bash
   npm run preview
   ```
